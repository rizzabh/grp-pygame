# Platformer Game
A dynamic and exciting 2D platformer built with Python and Pygame. Inspired by daily commutes on local trains and a love for vadapavs — collect Vadapavs, avoid hazards, and reach the goal!

## About
This is a lightweight 2D platformer created using Python and Pygame. Players navigate through levels filled with moving platforms, spikes, enemies, and other obstacles while collecting Vadapavs for points. The project is intended as a fun demo and a learning exercise in game development with Pygame.

## Features
- Smooth 2D sprite-based graphics
- Player movement and jumping
- Moving platforms and environmental hazards (spikes, pits)
- Enemies with simple behaviors
- Collectible items (Vadapavs / coins)
- Health system with game over and victory conditions
- Level progression and score tracking

## Controls
- Move left / right: Arrow keys or A / D
- Jump: Space or W
- Pause / Quit: Esc

(Controls may vary depending on how the main script maps input — check the code if you need to change bindings.)

## Installation
Make sure you have Python and pip installed.

### Prerequisites
- Python 3.6+ (3.8 or newer recommended)
- pip (Python package manager)

### Install Pygame
Run:

```bash
pip install pygame
```

## Running the game
1. Clone the repository:

```bash
git clone https://github.com/rizzabh/grp-pygame.git
cd grp-pygame
```

2. Run the main script (replace main.py with the actual entrypoint if different):

```bash
python main.py
```

If the project uses a different entrypoint (for example inside a src/ folder), run that file instead.
